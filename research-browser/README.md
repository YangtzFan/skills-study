# research-browser：研究协作与证据综合

协调网页、文档和图片等研究能力，将已核实的材料组织成有出处的结论。它还维护研究工件、项目知识库和外部调用的共享政策。

## 适用场景

- 将本地报告与公开资料比较，或综合多份来源解释一致与分歧。
- 研究需要在检索、文档抽取和图片分析之间衔接。
- 明确要求添加、更新、列出或移除项目知识库资料。

单一能力可以直接调用，普通解释与讲义续写不必启动完整研究流程。本技能名称中的 browser 也不表示每次都必须打开浏览器。

研究结果需要写成学习笔记或输出 Word 时，按 [AGENTS.md](../AGENTS.md) 和本技能的交接规则复用已有证据，保留出处与覆盖限制。仅转换已有 Markdown 不要求重新检索、抽取或问答。

## 使用示例

```text
使用 research-browser，比较这份本地报告与最新公开证据，
说明双方的结论、差异及证据限制，并保留来源。
```

```text
将这份资料加入当前项目知识库，保留原文件并登记可复用的抽取结果。
```

## 输入、结果与条件

提供研究问题、来源或入口、工作区，以及已有任务记录。结果可以是带出处的综合答复、已验证的文件或明确标注缺口的阶段成果；已有证据和授权会随任务衔接继续使用。

可用能力取决于宿主工具。需要保留的研究材料位于当前工作区的 `.agents-work/`；只有明确要求时才维护其中的项目知识库。外部调用遵循共享限额，读取本地资料不等于允许上传到第三方。

用户要求的笔记或 Word 成品使用指定位置，研究工件的 Markdown 约定不限制成品格式；生成这些成品本身也不要求创建研究目录或登记知识库。

详细规则见 [SKILL.md](SKILL.md)，顶层选择原则见 [AGENTS.md](../AGENTS.md)。
