# word-write：Markdown 写入 Word

以 Markdown 文件或内联 Markdown 为内容来源，生成新的 `.docx`，或将内容插入、替换到现有 Word 文档的指定位置，并沿用目标样式。

## 适用场景

- 将已有 Markdown 报告、笔记或讲义转换为可编辑的 Word 文档。
- 将 Markdown 内容写入现有报告的指定章节、书签或占位符，保留其他内容。
- 按提供的模板生成文档，核对标题、列表、表格、图片、公式等结构。

它负责转换、定位写入与格式核验；单纯阅读 Word、回答文档问题或只起草正文不需要调用本技能。需要同时起草时，可以先准备内联 Markdown，不必额外保存 `.md`。Word 格式的学习笔记如何衔接内容写作，见 [AGENTS.md](../AGENTS.md)。

## 使用示例

```text
使用 word-write，将 notes.md 转换为 notes.docx，
保留标题层级、公式和 [!TIP] 补充内容，原 Markdown 不变。
```

```text
使用 word-write，将 method.md 写入现有报告的“研究方法”章节，
替换该节正文，沿用模板样式，另存为报告_更新版.docx。
```

## 输入、结果与条件

提供 Markdown 内容、输出位置，以及涉及的图片等资源；写入现有文档时，还需提供目标文件和明确的插入或替换位置。可附模板、标题层级映射与格式要求。内联内容的相对资源路径需要可确定的基准目录。若没有原文，也未要求起草，会先说明缺少的内容。

结果是实际保存的 Word 文件、简要改动说明，以及影响使用的未验证事项。默认另存以保留原文档；明确要求覆盖时按已有授权执行。成品放在指定位置，无指定位置时放在任务工作区，不写入技能安装目录，也不自动登记为研究工件或加入知识库。

转换依赖可用的本地工具，例如 Pandoc，或 Markdown 解析器配合 Word 写入库。`python-docx` 本身不能解析 Markdown，也不负责分页和字段计算。缺少工具或功能支持时会说明具体限制，不会把粘贴原始 Markdown 当作完成转换，也不会未经适用授权上传到在线转换服务。

会核对转换后的文本、结构、写入位置和相关格式。版面重要时使用可用渲染器检查；仅通过文件或结构检查不代表已验证 Word 中的视觉效果。复杂公式、修订、字段或嵌入对象的保真程度取决于所用工具。

完整执行规则见 [SKILL.md](SKILL.md)，语义转换与现有文档处理细节见 [Markdown 转换参考](references/markdown-to-word.md) 和 [DOCX 编辑参考](references/docx-editing.md)。
