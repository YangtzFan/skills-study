# web-research：公开网页检索与研究

搜索公开信息、读取指定网页、下载公开文件，并用实际阅读过的来源支持答案。可以只完成一次查询，也可以围绕问题逐步补齐证据。

## 适用场景

- 查找资料、核实公开说法、比较不同来源。
- 阅读给定 URL，或下载并验证公开文件。

给定 URL 通常直接读取；只要求搜索时，可以返回候选来源。搜索摘要用于寻找线索，不等于已经读过全文。需要账号或机构权限的访问另有专门流程。

## 使用示例

```text
使用 web-research，查找这个技术方案的公开依据，优先阅读原始来源，
给出支持结论的链接，并说明来源之间的分歧。
```

```text
使用 web-research 阅读这个公开 URL，提炼与问题相关的内容并注明出处。
```

## 输入、结果与条件

提供问题、公开 URL 或下载目标，必要时说明时间范围和研究深度。结果可以是候选链接、带来源的答复，或附实际路径与格式检查结果的下载文件。

需要可用的搜索、网页读取、HTTP 或浏览器能力；普通公开访问不以浏览器为必需条件。动态页面可使用获授权的真实浏览器。技能不会自动安装服务，也不因模型名称就假定具备联网能力；私有资料和认证链接不会擅自发送给第三方。
