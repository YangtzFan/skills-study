# intuitive-study-notes：直观型学习笔记

编写、续写或润色中文理工科笔记与讲义，从读者已经理解的内容出发，逐步建立新概念，让读者看懂公式、计算及其适用条件。

## 适用场景

- 根据课件或编写大纲补写一节，延续已有笔记的讲解方式。
- 将公式密集、证明过多的内容改写为便于理解的学习材料。

主要特点是自然引入概念，用简单算例讲清关键步骤，算完后解释结果。短推导可以留在正文，复杂证明通常省略；少量重要证明或补充放入 `[!TIP]`，正文仍能独立读懂。不会为了统一形式而给每节强加工程背景或固定模板。

## 使用示例

```text
使用 intuitive-study-notes，根据大纲续写下一节。
沿用已有笔记的符号与层级，侧重直观理解，用小例子讲清过程。
```

```text
使用 intuitive-study-notes 润色以下讲义，保留必要条件与核心公式，
压缩复杂证明，把重要补充放入 [!TIP]，使概念之间自然衔接。
```

## 输入、结果与条件

提供主题或大纲，最好附现有笔记、参考材料、读者基础和编写范围。结果是可以直接阅读或写入指定文件的正文，保持必要的数学准确性与原有组织习惯。

本技能不依赖浏览器或其他研究工具。需要补充或处理来源时，再按实际缺口衔接相应能力；已有笔记中的错误不会作为风格继承。
