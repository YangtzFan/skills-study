# critical-reasoning：推理与答案质量检查

检查一个说法、方案或答案的前提、证据与逻辑，帮助区分已知事实、推断和仍待确认的部分。检查深度随任务的重要性和不确定性调整。

## 适用场景

- 核查论证是否跳步，数据、单位、比较口径是否一致，证据是否足以支持结论。
- 比较方案的收益、代价与适用条件，或在新证据出现后修正判断。

简单编辑与日常问答只做必要检查，不会自动扩展成研究报告。它可以利用当前材料独立工作；缺少证据时会指出具体缺口，不把已有材料的逻辑检查表述为已完成外部调查。

## 使用示例

```text
使用 critical-reasoning 检查下面的方案，重点看前提是否成立、证据是否充分，
指出会影响决策的问题，并说明哪些结论仍需验证。
```

## 输入、结果与条件

提供待检查的说法或方案，以及已有证据、目标和约束。结果通常包含关键问题、依据、适用边界与必要的修订建议；不会把猜测包装成事实，也不会输出内部思考过程。

本技能不依赖浏览器或其他技能。材料不足时会说明缺口；检查计划或配置本身，不能证明实际执行已经成功。
