# document-ingest：本地文档抽取

把本地文档转换为可阅读、可定位出处的文本与结构，同时记录未能提取的页面、表格或图片。需要复用时，可以保存 Markdown 工件。

## 适用场景

- 从 PDF、Word、表格或课件中提取正文、表格和来源位置。
- 保存可复用的 Markdown 抽取结果，或将派生文件写入已经选定的输出目录。

抽取任务可以在得到文本与覆盖说明后结束，不必继续问答。已有可读正文时，通常无需重复抽取。

## 使用示例

```text
使用 document-ingest 抽取这份本地 PDF，保留页码，
直接返回正文和未覆盖内容，不保存中间工件。
```

```text
使用 document-ingest 持久化抽取这份课件，保留幻灯片编号，
保存可复用的 Markdown 正文、分块和元数据。
```

## 输入、结果与条件

提供文件路径或明确选定的文件集合。一次性抽取默认使用 `immediate`，返回文本、出处和覆盖限制，不需要已有任务目录；`persistent` 保存 `content.md`、`chunks.md`、`metadata.md`，可使用已指定的派生文件根目录。

本技能负责抽取及其元数据，不修改项目知识库登记表。项目资料的选择、登记、替代关系和移除由 [research-browser](../research-browser/SKILL.md#knowledge-base-operations) 统一管理；把抽取文件写入指定目录本身不代表已完成知识库登记。

格式支持取决于已安装的本地解析器和 OCR 工具，不会自动安装依赖或上传到外部转换服务。原文件保持只读；解析成功不等于内容提取完整，扫描图、复杂公式和版面可能需要额外处理。CAJ/KDH 改扩展名不能变成 PDF。

详细执行规则见 [SKILL.md](SKILL.md)，保存位置与知识库规则见 [共享研究政策](../research-browser/SKILL.md)。
