# Edge Browser Research 使用说明

通过获授权的本地 Microsoft Edge 会话完成网页认证、学术数据库论文检索和对应下载验证。适用任务与跨技能衔接以 [AGENTS.md](../AGENTS.md) 和 [research-browser](../research-browser/SKILL.md) 为准；本说明不另设路由或预算。

本技能是供代理执行的规则，需要宿主浏览器工具或可用的本地 CDP 能力，不是独立启动器或会话管理程序。密码、MFA 和 CAPTCHA 由用户在浏览器中完成。

## 入口与条件

- [SKILL.md](SKILL.md)：输入、连接、Windows/Linux 启动示例、检索、下载与完成标准。
- [任务会话参考](references/task-sessions.md)：任务记录字段、地址筛选、窗口归属、恢复与关闭。
- [共享研究政策](../research-browser/SKILL.md)：工件、知识库和外部调用预算。

需要可用 Microsoft Edge 和获授权的控制接口；手动认证需要可交互的图形环境。优先复用已知、获授权的研究实例。默认 CDP 端点是 `http://127.0.0.1:9222/json/version`，控制前核对实例与配置归属。端点可连接不代表已接入正确配置，普通浏览器窗口也不一定可控。

实际导航、表单、下载事件与窗口控制依赖当前宿主工具或 CDP 协议；不要假设存在额外 helper 或恢复程序。

## 配置与任务记录

| 内容 | 位置 | 用途 |
| --- | --- | --- |
| Windows 浏览器配置 | `%LOCALAPPDATA%\CodexBrowser\EdgeResearch` | 同一 OS 用户跨项目保留浏览器偏好和登录状态 |
| Linux 浏览器配置 | `$XDG_CONFIG_HOME/codex-browser/edge-research`；变量不是绝对路径时使用 `$HOME/.config/codex-browser/edge-research` | 同一 Linux 用户跨项目复用 |
| 任务恢复记录 | `<workspace>/.agents-work/<task-id>/browser/session.json` | 经过筛选的安全页面地址、来源标识、检索与恢复进度 |
| 任务证据与索引 | 同一任务的 `index.md`、`downloads/` 等 | 登记来源、用途、文件与验证状态 |

按运行浏览器的操作系统和用户解析配置。WSL/容器代理控制 Windows Edge 时使用 Windows 用户配置；不同系统不共用正在使用的目录。

任务记录不保存浏览器配置、Cookie、密码、认证跳转或 Chromium `Sessions/` 文件。浏览器自身的历史、缓存和内部会话仍可能留在全局配置中。不同任务窗口共享站点存储和登录状态，不能隔离账号；并发下载还需协调浏览器级设置。

## 新任务、继续与结束

| 场景 | 行为 |
| --- | --- |
| 新任务 | 共享研究配置中的独立空白窗口；核对实际启动页面 |
| 继续 | 复用已确认归属的任务窗口；必要时仅恢复该任务的安全记录 |
| 暂停/结束 | 保存必要进度；按已有授权关闭确认归属的页面，保留全局配置 |

任务由当前请求和已有任务目录确定，不由最近修改时间或碰巧打开的页面决定。窗口/标签 ID 只在当前实例内有效，不作为持久恢复键。归属不明的窗口保持原状。

启动参数、启动设置和实际窗口分别核对：`--new-window about:blank` 不能排除策略或崩溃恢复打开旧页面。每次下载前重新指定本任务目录，避免沿用其他任务的保存位置。

恢复记录使用 `navigate` 或 `entry-and-search`，后者关联明确的来源和检索词。URL 不能恢复完整表单、POST 查询、滚动位置或历史，也不能延长登录有效期。跳转认证应记录为“需要重新认证”；不把认证地址写入记录。

## 请求示例

```text
使用 edge-browser-research，通过我授权的学校图书馆入口检索论文。
这是新任务；密码或验证码由我手动处理。
```

```text
继续当前工作区 .agents-work/<task-id> 的任务。
优先复用该任务已打开的窗口，必要时仅恢复它的安全记录。
```

```text
保存当前任务的页面与检索进度，然后只关闭这个任务的页面。
保留全局研究配置。
```

## 常见故障与验证

| 情况 | 处理 |
| --- | --- |
| 重启后出现旧任务页面 | 检查启动选项、策略与崩溃恢复；仅处理已确认归属且获准清理的页面 |
| 设置控件 DOM 文本为空 | 用正常 UI 或无障碍树检查标签和选中状态 |
| 调试端口占用或配置已在使用 | 核对实例，不删锁、不启动竞争实例、不结束未知进程 |
| 页面可开但下载找不到 | 检查目标目录、完成事件/历史及实际文件，不盲目重复点击 |
| Linux 无图形环境 | 报告手动认证限制，或使用已有获授权的可交互会话 |

分别报告配置选择、任务窗口归属、当前网站认证、文章访问、下载完成、格式验证和内容可读性。配置存在、Cookie 数据库存在或显示机构名都不能证明其他状态。

结构检查只核对字段、路径和示例。真实站点权限与下载能力须在实际任务及其授权/预算内验证；一篇文章的成功不能推广到所有数据库、年份或格式。任务会话变更的验收场景见[会话参考](references/task-sessions.md#acceptance-checks)。
