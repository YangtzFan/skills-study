# document-qa：基于文档的问答

从提供的文档文本或已有抽取结果中寻找证据，回答问题并标明出处。重点是忠实于材料，同时说明实际阅读范围和仍未覆盖的内容。

## 适用场景

- 查找定义、结论或原文，回答“文档中如何解释这个问题”。
- 总结或比较文档内容，检查指定主题的覆盖情况。

它负责文档内的检索与回答，不负责抽取原文件、核实外部事实或登记知识库。可以直接使用可读文本，无需先运行其他技能或生成文档 ID。

## 使用示例

```text
使用 document-qa，根据以下正文解释作者的结论，
引用关键原文并标注章节；材料没有支持的部分请明确说明。
```

```text
使用 document-qa，检查已有抽取结果是否覆盖这些主题，
区分已核实内容、未检查部分和抽取缺口。
```

## 输入、结果与条件

提供具体问题，以及可读正文或已有工件路径，尽量附原文件名称和页码、章节或幻灯片编号。结果包含有依据的回答、可回查的出处，以及影响结论的材料缺口。

局部检索没有找到，不等于全文不存在；全文总结与完整性检查需要相应覆盖。缺少可读证据时会说明具体问题，不用外部知识补成“文档说法”。本地资料不会未经授权发送给远程检索服务。

详细执行规则见 [SKILL.md](SKILL.md)，技能选择与衔接见 [AGENTS.md](../AGENTS.md)。
