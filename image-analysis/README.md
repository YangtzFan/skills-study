# image-analysis：图片证据分析

读取截图、扫描页、图表和示意图，提取文字或解释视觉信息，并保留来源、使用方法和不确定之处。

## 适用场景

- 辨认图片中的文字、数字、标签和表格。
- 解释图表、布局或示意图，补充文档文本抽取遗漏的视觉信息。

可以直接提供图片，不需要文档 ID 或预先抽取。OCR 文字识别、宿主视觉理解和外部模型中转属于不同方法，会分别说明；视觉模型的转录不会冒充独立 OCR 结果。

## 使用示例

```text
使用 image-analysis 分析这张表格图片，核对关键数值与单位，
标明难以辨认的单元格，优先使用现有宿主视觉或本地 OCR。
```

```text
使用 image-analysis 解释这张示意图中各部分的关系，
区分图中直接可见的信息和推断。
```

## 输入、结果与条件

提供图片路径、附件或公开图片 URL，并说明关注的问题；若来自文档，附页码或幻灯片位置。结果是提取内容、视觉解释及影响答案的识别限制，必要时保留分析工件。

需要可用的本地 OCR、宿主视觉或获授权的图片模型能力，不会自动安装依赖。外部中转还需要已配置的兼容模型；上传本地或非公开图片需要明确授权。缺少 OCR 时仍可用其他可用方法，但会说明无法独立核对文字。
